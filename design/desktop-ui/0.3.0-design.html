Linux 安装说明

两种格式 × 两种架构。说明卡只给可复制命令，不做图形安装器。

deb + rpm · x64/arm64

Debian / Ubuntu

.deb
Ubuntu 22.04+ / Debian 12+
# x64 sudo apt install ./pi-carry-linux-debian-12-x64-0.3.0.deb # arm64 sudo apt install ./pi-carry-linux-debian-12-arm64-0.3.0.deb # 校验 sha256sum -c SHA256SUMS --ignore-missing

Fedora / RHEL

.rpm
Fedora 39+ / RHEL 9+
# x64 sudo dnf install ./pi-carry-linux-fedora-39-x64-0.3.0.rpm # arm64 sudo dnf install ./pi-carry-linux-fedora-39-arm64-0.3.0.rpm # 校验 sha256sum -c SHA256SUMS --ignore-missing
依赖缺失：`libwebkit2gtk-4.1-0` 未安装。请先执行 sudo apt install libwebkit2gtk-4.1-0 libayatana-appindicator3-1，再重新安装。
升级：sudo apt install ./pi-carry-…-0.3.1.deb 或 sudo dnf upgrade ./…rpm。应用内更新也会调用包管理器（需 polkit 授权）。
命令优先：所有 Linux 说明以可复制命令为准，不写「双击安装」。
架构显式：文件名包含架构，避免用户下错包；`dpkg -i` 不推荐（不解决依赖）。
依赖声明：deb `Depends: libwebkit2gtk-4.1-0, libgtk-3-0, libayatana-appindicator3-1`；rpm 同名 Requires。
更新失败：polkit 拒绝时提示「未获得系统授权，请手动执行上面的命令」，不重试。

任何一项缺失都不允许发布；`signature` 必须来自对应 `.sig`，不能手写。
单一事实源：`latest.json` 由 `scripts/gen-latest-json.mjs` 从构建产物生成，禁止手改。
键名核对：平台键须与 updater 实际输出一致；首轮用 `RUST_LOG=tauri_plugin_updater=debug` 打印后固化。
便携段：仅 Windows 有；便携版不参与 updater 验签，靠 sha256 与版本比较。
审计：发布后保留 `SHA256SUMS` 与 `.sig` 至少 2 个版本，便于回滚核对。

原型边界

这里能实现的：横幅、更新对话框、进度与失败态、设置卡片、首启自检、密钥降级、深链预填、托盘菜单、安装说明卡、发布清单可视化 —— 全部由 `design/desktop-ui/index.html` + `app.js` 的原生 DOM 实现，不引入框架。

这里只是示意：NSIS 三屏是 Windows 系统向导的外观，不可自绘；DMG 窗口由 `bundle.macOS.dmg` 的背景图与图标位置决定；macOS 的 Gatekeeper 提示是系统弹窗，应用只能提供说明。

配色：所有颜色取生产变量（`--ink #05050a`、`--violet #7c6bff`、`--cyan #45d9d0`、`--rose #ff6b85`、`--amber #ffb86b`、`--mint #5be7a9`）；新增界面不要引入第二套主题。

配套计划：plan/0.3.0.md §12；实现后请以真实截图为准确认本稿，不要直接照搬像素。
