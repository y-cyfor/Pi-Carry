外观

跟随 Windows 的黑夜 / 白天模式，或固定为黑色、白色。切换立即生效，并记住选择。

节点

显示在手机节点列表中的名称，以及要托管的 pi 可执行文件。
留空使用 PATH 中的 pi；也可以填写绝对路径。
手机默认 control；桌面配对会自动申请 full（上限 3 台）。

传输

直连优先；relay 只用于 NAT 穿透失败时中继加密流量。
n0 提供开箱即用的穿透，但中继节点会看到连接元数据。
每行一个，仅“自托管”模式使用。
局域网 mDNS 发现在同一网段广播节点地址；需要系统允许组播。

托盘与启动

关闭窗口时最小化到托盘桥接服务继续运行，手机仍可连接。
开机自动启动登录 Windows 后在托盘启动 pi carry。
