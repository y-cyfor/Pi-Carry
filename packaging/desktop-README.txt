pi carry 0.2.0（Windows x64 便携版）

运行要求
- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime（Win11 与大部分 Win10 已自带）
- 本机已安装并可使用 pi

启动
- 保持 pi-carry-desktop.exe 与 WebView2Loader.dll 在同一目录，双击 exe。
- 程序常驻系统托盘，关闭窗口不会退出。
- 托盘菜单可重新打开窗口、开始配对或退出。

配对手机
1. 在桌面端打开“配对手机”，点击“生成二维码”。
2. 手机端安装 Android APK，在配对页扫描二维码；同一局域网会优先直连。
3. 也可以手动输入 Endpoint ID 和桌面端显示的 6 位码。
4. 配对成功后，手机端可查看会话、发送消息、处理审批、切换模型/思考等级。

外观
- 桌面端“设置 → 外观”与手机端“设置 → 外观”都提供自动/黑色/白色三档，默认跟随系统。

数据
- 配置、密钥、日志：%USERPROFILE%\.pi-carry\
- 卸载：退出托盘程序后删除该目录即可；手机端可在设置中移除节点。

注意
- 桌面端不会代替手机批准工具调用；高风险操作必须在手机端确认。
- 4G 连接依赖 n0 relay 或你在配置中设置的自托管 relay。
