pi carry 0.1.1（Android 正式版）

运行要求
- Android 8.0（API 26）或更高版本
- arm64-v8a 或 x86_64 设备
- 手机与电脑在同一局域网，或电脑已连接可用的 iroh relay

安装
- arm64 手机安装 pi-carry-android-8.0-arm64-v8a-0.1.1.apk；x86_64 模拟器安装 pi-carry-android-8.0-x86_64-0.1.1.apk。
- 这是正式签名的发布包，首次安装需要在系统设置中允许安装未知来源应用。

配对
1. 在电脑上启动 pi-carry-desktop，进入“配对手机”，点击“生成二维码”。
2. 手机打开 pi carry，进入“配对”，扫描二维码；也可以手动输入 Endpoint ID 和 6 位码。
3. 同一局域网优先直连；失败后自动尝试 relay。
4. 配对成功后即可查看会话、发送消息、处理审批、切换模型与思考等级。

权限
- 相机：扫描配对二维码。
- 通知：前台服务与审批提醒；拒绝后仍可在应用内处理审批。
- 网络：连接电脑端桥接服务。
- 开机自启：可选，用于保持远程连接。

数据与卸载
- 节点、设置保存在应用私有存储；卸载应用会清除这些数据。
- 在电脑端“设备”页可立即吊销丢失的手机。

注意
- 桌面端不会代替手机批准工具调用；高风险操作必须在手机端确认。
